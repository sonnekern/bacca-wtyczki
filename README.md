# Bacca - oficjalne wtyczki

Oficjalne repozytorium wtyczek i aplikacji towarzyszacych rodziny **Bacca SongBook**.
Adres manifestu do wpisania w ustawieniach SongBooka:

```
https://raw.githubusercontent.com/sonnekern/bacca-wtyczki/main/manifest.json
```

- `plugins` - wtyczki w formacie, ktory SongBook juz obsluguje (`base_url` tylko https).
- `aplikacje` - aplikacje dzialajace obok SongBooka na tym samym urzadzeniu (np. Bacca Sonus).
  Do ich lokalnego adresu SongBook nie wysyla klucza API ani tokenu konta.
  Starsze wersje SongBooka te liste pomijaja.

Wszystko w rodzinie Bacca jest darmowe.
